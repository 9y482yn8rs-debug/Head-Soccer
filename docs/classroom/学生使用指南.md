# 大头足球：学生项目 v1

你将接手这个项目，先玩一局，再读一小段代码，最后完成自己的第一项改动。

## 第一次启动

先解压整个压缩包；不要直接在压缩包里运行。打开包含 main.py、requirements.txt、assets 的文件夹。需要安装 Python（教师当前验证环境为 Python 3.13.3、Pygame 2.6.1）。建议课堂统一 Python 3.13，不要直接使用不确定兼容性的新版本。

Windows：在这个文件夹打开 PowerShell，逐行执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

macOS：在终端进入这个文件夹，逐行执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

这是直接运行 Python 主文件，无须 bat。以上命令不需要激活虚拟环境；以后只运行最后一行。路径有空格时，使用 `cd "你的项目完整路径"`。在编辑器运行时，选择本项目 .venv 的解释器，打开 main.py 后运行。

依赖安装首次需要网络；安装完成后游戏和规则 AI 均可离线运行，无须 API Key。Windows 已验证；Mac 已提供路径和字体支持，仍需要课前在学生实际 Mac 上试运行。

## 怎么玩

- 首页选择“单人 VS 电脑”或“本地双人”。单人可选简单、中等、困难。
- 你控制红队：WASD 上下左右，按两键斜走，空格踢球。
- 双人时蓝队：方向键移动，Enter 踢球；单人时由电脑控制蓝队。
- 移动方向同时用于瞄准；松开方向键会保留最后方向。靠近球时淡色尖角提示踢球方向。
- 球员在草地平面移动，没有跳跃；接触可带球，靠近且方向合适才能踢到球。
- 红队进右门，蓝队进左门；整球穿过门口得分。90 秒后比分高者胜。
- Tab 切模式；单人首页 1/2/3 选难度；空格开始；比赛结束 R 重开；Esc 回首页并重置本局。

第一次先选简单。困难档会回防和绕开挡球的人，但仍使用正常移动、碰撞和踢球规则。

## 先读哪里

| 文件 | 负责什么 | 今天重点 |
|---|---|---|
| ai_settings.py | 三档电脑参数 | 改一个数值，预测结果 |
| ai.py | 电脑观察、判断、输出操作 | should_defend 函数 |
| settings.py | 速度、场地、时间等常量 | PLAYER_SPEED |
| player.py | 球员移动与踢球 | 方向、冷却 |
| ball.py / collision.py | 球运动与碰撞 | 后续进阶 |
| match.py | 计时、进球、胜负 | 条件判断 |
| main.py | 把输入、规则和画面连起来 | 理解调用关系 |
| field.py / scenery.py / resources.py / ui.py | 投影、场景、加载与界面 | 暂不要求读懂 |

从《学生练习》开始，记录到《学习记录》。先理解一个小函数，不必一次读懂所有代码。

## 常见问题

- 提示没有 pygame：用上面同一条 .venv 内 Python 命令安装依赖，避免装到别的解释器。
- 找不到 main.py：先进入包含它的目录；不要只复制 main.py，assets 也必须保留。
- 中文字体错误：请教师检查系统中文字体，或提供开源 Noto Sans SC 字体到 assets/fonts/NotoSansSC-Regular.ttf。
- 窗口没响应按键：先点击游戏窗口；如果比赛已经结束，按 R。
- 修改没生效：保存文件、关闭游戏、重新运行；课堂不要同时改多个参数。

教师或进阶学生可运行 `.venv/bin/python -m unittest discover -s tests -v`；Windows 将前面的 Python 路径换成 `.venv\Scripts\python.exe`。
