# 地面自由移动版玩法设计

## 本版目标

将单线侧视足球改为有纵深的地面足球。玩家能绕开对手、斜向接近足球、选择射门角度。取消跳跃、重力和离地高度，保留简单的二维物理，适合 Python 教学。

## 坐标与视觉

物理世界：x 为左右，y 为场地前后，向下为正。球员位置为脚底地面中心；足球位置为球在地面的投影中心。球场范围 x=100–1180、y=0–620。

field.py 统一负责把地面位置投影到屏幕。B 方案把地面 y=0–620 映射到屏幕 y=364–698，横向及人物大小由远端 0.86 倍缓慢过渡到近端 1.08 倍；球门美术高度也使用相同的纵深缩放。物理碰撞完全不依赖屏幕坐标，透视不会改变球员占地大小或射门力度。

球员与足球按地面 y 从远到近绘制，球门前柱与横梁也加入排序。阴影贴在地面，足球图片向上偏移一个显示半径，表现贴地滚动。脚下使用自然软阴影，不再绘制红蓝队色圈。接近足球时显示小型暖白色方向尖角，远离球时隐藏，踢球动作中略微加亮；没有常驻的彩色箭杆。

移除底部说明栏后扩大的真实可移动范围继续保留；B 方案近端边线到屏幕 y=698，近端稍宽，整个球场依然可见。球门开口位置与宽度按世界坐标绘制，和进球判定一致。操作说明与规则集中展示在开始界面，比赛画面不再显示底部说明栏。

## 移动与方向

红队 WASD、蓝队方向键，两个方向合成后归一化。真人球员直跑和斜跑世界速度均为 280 单位/秒；电脑按难度使用 52%、82%、100% 的速度。相反方向同时按下时互相抵消。

没有方向输入则停止移动并保留上次瞄准方向。纯上下移动保留人物左右侧身朝向，近球时的小尖角准确提示瞄准方向。开球时红队向右、蓝队向左。

## 踢球、带球和抢断

红队空格、蓝队 Enter。先读取本帧方向，再锁定踢球方向；一次动作中即使改方向，也不改变这次踢球的方向。踢球持续 0.16 秒、冷却 0.30 秒，一次动作最多命中一次，按住不连发。

足球必须在面前约 100 度扇形内，距离球员地面中心不超过 76 单位。命中后速度设为该方向 740 单位/秒，八方向力度一致，不做随机散射或自动瞄准。

球员地面半径 25，足球半径 16。普通身体接触轻推球；主动踢球速度明显更高。球不绑定任何一位玩家，因此可被抢走。球员之间重叠时互相推开，前后错开后可以绕过。

## 足球与边界

足球只在地面滚动，摩擦按时间指数衰减，方向保持不变直到碰撞或再次被踢。速度上限 800，低速时停住。旋转只用于视觉表现。

场地上下和门外侧边反弹；左右门口的纵深范围均为 y=190–430。只有整个球位于门口范围、且整个球穿过门线才计分。门口端点有碰撞，防止斜射贴柱穿过。没有高低球、横梁高度判定、界外球或角球。

## 比赛流程

首页 → 比赛 → 进球庆祝 → 开球继续；时间耗尽进入结果页。90 秒包括进球庆祝，时间到后不再接受进球。重开和回首页会重置位置、朝向、动作与比分。

## 本版取舍

先使用现有左右侧身人物素材，动作包含站立、两帧跑步和踢球；不加载跳跃图。采用已选 B 方案派生的干净背景，保留卡通看台氛围并增加草地纹理。scenery.py 在加载时绘制和缓存条纹、场线及白色立体球门；ui.py 绘制软阴影和近球方向提示。球门网面透明，前后层分别处理遮挡。

后续可独立补充八方向角色动作、音效与更细腻的球门视觉；不需要为此重新引入跳跃或三维物理。

## 单人与电脑（当前已实现）

首页可选择本地双人或单人对电脑，并选择简单/中等/困难。单人时仅红队接受真人输入，蓝队由规则型 AI 操作。难度通过反应间隔、速度、预判、回防和射门线路决策区分；详见 classroom/AI任务书与实现说明.md。无新增跳跃或球的高度。
